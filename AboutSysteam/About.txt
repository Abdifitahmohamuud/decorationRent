## System Overview
The **decoration‑rental** project is a full‑stack application consisting of a Next.js web frontend/backend and a separate mobile application (React Native) located under `decorationRent/mobileApp`. The web portion serves both the public site and an API consumed by the mobile client.

### Technology Stack
- **Web (Next.js)**:  TypeScript, Tailwind (or vanilla CSS), Next.js API routes.
- **Backend**:NExt js same , i use as backend + frontend  Prisma ORM, PostgreSQL (or MySQL), server‑side logic in `app/api`.
- **Authentication**: NextAuth.js with JWT session strategy (custom provider if any).
- **Mobile**: flutter in `decorationRent/mobileApp`, communicates via the same REST API.
- **DevOps**: PNPM workspaces, Docker for containerisation, Vercel/Netlify for deployment.

## API Endpoints Overview
| Method | Route | Description | Request Body | Response |
|--------|-------|-------------|--------------|----------|
| GET | `/api/decorations` | List all decorations | - | `{ decorations: Decoration[] }` |
| POST | `/api/decorations` | Create a new decoration (admin) | `{ name, price, images, description }` | `{ success: true, decoration: Decoration }` |
| GET | `/api/decorations/[id]` | Get details of a decoration | - | `{ decoration: Decoration }` |
| PUT | `/api/decorations/[id]` | Update a decoration (admin) | `{ name?, price?, images?, description? }` | `{ success: true, decoration: Decoration }` |
| DELETE | `/api/decorations/[id]` | Delete a decoration (admin) | - | `{ success: true }` |
| POST | `/api/bookings` | Create a booking | `{ decorationId, startDate, endDate, userId }` | `{ booking: Booking, paymentUrl: string }` |
| GET | `/api/bookings/[id]` | Retrieve a booking | - | `{ booking: Booking }` |
| POST | `/api/auth/login` | User login | `{ email, password }` | `{ token, user }` |
| POST | `/api/auth/register` | Register new user | `{ name, email, password }` | `{ user, token }` |
| GET | `/api/profile` | Get current user profile (auth required) | - | `{ user }` |

## Feature Overview
- **Decoration Catalogue** – Browse, search, and filter decorations.
- **Booking System** – Reserve decorations for specific dates, integrated with payment gateway.
- **User Authentication** – Sign‑up, login, JWT protected routes.
- **Admin Dashboard** – Manage decorations, bookings, users, and view analytics.
- **Responsive Design** – Works on desktop, tablet, and mobile browsers.
- **Mobile App Sync** – Mobile client uses the same API for booking and browsing.

## Communication Between Web & Mobile
Both the web frontend and the flutter mobile app consume the same REST API under `/api/*`. Authentication is token‑based (JWT) and stored securely on the client. The API enforces role‑based access (user vs admin) using middleware defined in `app/auth/middleware.ts`.
